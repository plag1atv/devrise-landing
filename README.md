# DevRise - Landing for Online Web Development Courses

Современный минималистичный лендинг образовательной платформы **DevRise**.

---

## О DevRise

DevRise - это сайт онлайн-курсов по веб-разработке для:

* Студентов
* Новичков в IT
* Людей, меняющих профессию

---

## Tech Stack

**Backend:**

* Python 3
* Flask

**Frontend:**

* HTML5
* CSS3 (Glass UI, gradients, animations)
* JavaScript (ES6)

**Дополнительно:**

* Custom Select (JS)
* Scroll Reveal анимации
* CSS Marquee animation
* Responsive layout

## Ключевые особенности

* Минималистичный дизайн с градиентами
* Glass-morphism UI
* Кастомные dropdown-компоненты (замена стандартных select)
* Бесконечная анимированная лента отзывов
* Адаптивная верстка
* Чистая структура Flask-приложения
